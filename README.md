# Abdulmalik Pharmacy Website Package

Static multi-page website package prepared for Abdulmalik Pharmacy.

## Pages
- Home
- Prescription Refill
- Shop / OTC categories
- Pharmacist Consultation
- Health Resources
- About
- Contact

## Before publishing
Replace these placeholders:
- +251 900 000 000
- WhatsApp link https://wa.me/251900000000
- Google Maps pin
- Opening hours if different
- Logo/brand assets
- Social media links
- Any product catalogue data

## Important
Forms are demonstration-only. They currently show a confirmation message in the browser. Connect them to a secure backend, email service, WhatsApp workflow, or database before using them for real customer/prescription data.

Do not publish unsupported accreditation claims (for example HIPAA/NABP) unless the pharmacy actually holds the relevant status.

## Free hosting
This package is static and can be deployed to GitHub Pages or Cloudflare Pages. A custom domain is optional and can be connected separately.
