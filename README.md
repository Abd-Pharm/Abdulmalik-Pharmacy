# Abdulmalik Pharmacy Website — Functional Version

## What now works
- Prescription/refill request form opens WhatsApp with a pre-filled request.
- Pharmacist consultation form opens WhatsApp with a pre-filled message.
- Product availability search opens WhatsApp with the requested product.
- Shop categories are clickable availability enquiries.
- Contact page includes Google Maps search/directions for Abdulmalik Pharmacy, Konel, in front of Juma Mosque, Dire Dawa.
- Phone click-to-call and WhatsApp buttons are active.
- Privacy page added.

## Before connecting a future backend
Do not collect prescription or health information in an unsecured public database. If you later add online forms, use a secure backend and review applicable Ethiopian health-data and privacy requirements.

## Publishing
Upload all files and folders to the root of the GitHub repository, preserving the `assets` folder structure. Do not upload the ZIP itself.
